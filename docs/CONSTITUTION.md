# Constitution

## What This Is

dbl-policy provides versioned, explicit policy artifacts for governance (G).

## Governing Principles

1. **Policy produces DECISION events only.**
2. **Immutable versions.** Published policy versions are never modified.
3. **Default deny.** Missing or invalid inputs result in DENY.

## What This Is Not

- Not an execution engine.
- Not a boundary layer.
- Not a domain framework.
